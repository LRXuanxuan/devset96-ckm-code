# 从系统模型到 LS、LMMSE 与传统 CS：第一阶段开发入口

日期：2026-10-29。当前阶段已完成可运行的 M0 模型、三种基线、数学正负控制，以及与 release_05 的接口连接。**M0 的数值结果是静态理想频域对照，不是原始数据集的 2 ms 未来 CSI 预测成绩。**

先读本文的第 1–4 节，再运行程序。现阶段无需增加网络，也无需重新生成 RT 数据。

## 1. 先定义最终要解决的问题

给定时刻 t0，在区间 [t0−4 ms,t0] 收到已知导频产生的观测，并拥有带噪位置、速度、姿态报告及历史地图。目标是预测 t*=t0+2 ms 的传播信道：

\[
\widehat H_* = f\!\left(Y_{\le t_0},X,W,\widehat s_{\le t_0},\widehat{\mathcal M},\sigma_n^2\right),
\qquad H_*\in\mathbb C^{16\times64\times16}.
\]

最后一维是 16 个指定目标频点。当前观测为 57 个 OFDM 符号、16 个 Rx 阵元、256 个 FFT bin。这两个频率网格不同：16 个目标频点中有 **10 个不与 FFT bin 精确重合**，不能把最近 bin 当作同一个目标。

| 数学对象 | 实际字段 | 算法权限与含义 |
|---|---|---|
| Y[s,r,k] | sample['input']['observation']['full_fft'] | 全部可用接收频域观测 |
| X[s,k] | observation['symbols'] | 已知发射符号，当前为单位模 QPSK |
| W[s,q] | observation['tx_beams'] | 已知发射波束，行表示 w_s^T |
| 精确接收时刻 | observation['receive_time_sec'] | 包含符号内采样时间 |
| 发射符号起点 | observation['start_sample']/fs | 与 CP、NFFT 一起定义完整波形 |
| 噪声方差 | observation['noise_variance'] | 每个复采样的 E|n|²；单位 FFT 后不变 |
| CFO 先验 | observation['cfo_prior_std_hz'] | CFO 真值不可用 |
| 历史地图 | sample['input']['map'] | 功率统计及有限测量信息，不是精确路径 |
| 目标时刻 | sample['input']['task']['target_time_sec'] | 已知任务要求 |
| 目标频率 | sample['target_frequencies_hz'] | 已知输出网格，不是信道真值 |
| H* | sample['target_csi'] | 仅作训练监督与评价，不能进入推断 |
| bookkeeping | sample['metadata'] | 用于分组，不输入模型 |

当前监督是传播 CSI，接收端观测还包含振荡器 CFO。若将最终目标改为“包含 CFO 相位的有效信道”，需另立标签与指标协议；两者不能混用。

## 2. 完整接收模型是什么

令 N=256，采样率 Fs=30.72 MHz，CP 长度 Ncp=64；发射阵元 q 的连续基带波形记为 x_q(t)。它由已知 OFDM 符号、波束和各符号的真实有效区间构成。接收样本时刻 t_n 的左侧已准入 RT anchor 为 a(n)，参考时刻为 t_a。与现有模拟器对应的局部模型为

\[
y_r[n]=e^{j2\pi\epsilon t_n}
\sum_{\ell\in\mathcal L_{a(n)}}
b_{\ell,a}\,e^{j2\pi\nu_{\ell,a}(t_n-t_a)}
a_{r,\ell,a}^{\mathrm{rx}}
\sum_{q=1}^{N_t}a_{q,\ell,a}^{\mathrm{tx}}
x_q(t_n-\tau_{\ell,a})+n_r[n].
\]

- ε 是公共 CFO，ν 是每条传播路径的 Doppler；两者物理来源不同。
- b 是 anchor 时刻参考阵元上的复系数，已经包含所声明的载波传播相位，不应再次乘相同的 exp(−j2π fc τ)。
- τ 是连续时延；现有实现直接计算分数时延的 OFDM 波形，不把 τ 强制取整到采样点。
- a_rx、a_tx 是阵列相位响应。按当前数据约定，发射端乘积为 a_tx^T w，不额外共轭一次。
- 每个接收样本选择相应左 anchor；路径集合、阵列姿态和参数可随 anchor 改变。
- N 的 DFT 使用正交归一化；复白噪声方差在 FFT 后保持不变。

该模型容纳符号内变化、ICI 和有限 CP 时的符号间干扰。其数值有效性仍受原档案的传播模型和局部准入范围限制。代码对应 [mimo_observation.py](../../sionna_small_validation/validation/mimo_observation.py)，上述式子是对已读实现的整理。

可将其概括为 Y=F_P(ξ)+N，H*=T*(ξ)。ξ 是跨历史与目标的动态参数，P 是已知发射协议。**一般不存在一个无需额外动态假设、只依赖导频的固定矩阵 A，使真实历史观测满足 Y=A vec(H*)+N。** 当前困难首先在这里，而不在 LS 的函数怎么调用。

## 3. 本轮先解决 M0：常信道、零 CFO 的理想频域模型

暂时把整个训练区间的传播信道视为常数，令 CFO=0，并假设定时/CP 条件使循环卷积模型成立。则

\[
Y_{s,r,k}=X_{s,k}\sum_{q=1}^{N_t}W_{s,q}H_{r,q,k}+N_{s,r,k}.
\]

这里 s 是符号，r 是接收阵元，q 是发射阵元，k 是 FFT 频点。当前已知符号模长为 1，因此

\[
Z_{s,r,k}=Y_{s,r,k}/X_{s,k}
=\sum_q W_{s,q}H_{r,q,k}+\widetilde N_{s,r,k},
\qquad \mathbb E|\widetilde N|^2=\sigma_n^2.
\]

**Z 是经过波束投影的信道，不是完整的 H。** 对每个 r,k，定义 h_{r,k}=[H_{r,1,k},…,H_{r,Nt,k}]^T，则

\[
z_{r,k}=W h_{r,k}+\widetilde n_{r,k},
\quad z_{r,k}\in\mathbb C^S,\quad W\in\mathbb C^{S\times64}.
\]

把所有接收阵元和频点放在不同列上，得到 Z=WC+N，其中 C∈C^(64×(16·256))。这里没有对 W 的物理前向乘法加共轭；最小二乘中出现 W^H 是求解复数优化问题的结果。

固定波束时 rank(W)=1；当前轮换波束时 rank(W)=57<64。后一种情况仍有 7 维发射方向零空间，所以无约束完整信道不可唯一恢复。若只用最后一个19符号 burst，空间欠定程度还会增加；“缩短窗口就能直接用 LS”也不是完整答案。

## 4. 三种已实现的基线

### 4.1 最小范数 LS

\[
\widehat C_{\rm LS}=W^\dagger Z.
\]

W^† 是 Moore–Penrose 广义逆。实现使用 np.linalg.lstsq，不计算奇异的 (W^H W)^{-1}。无噪声时，估计是 P_W C，其中 P_W=W^†W；误差为未观测方向 (I−P_W)C。给这个基线命名为“minimum-norm LS”，不要暗示它找回了所有发射方向。

若真实 C 的列满足各向同性单位协方差，则期望总误差除以期望总能量等于 (Nt−rank(W))/Nt。该公式依赖各向同性假设，不是每个实际信道的误差下界数值。

### 4.2 全局空间 LMMSE

在零均值模型中，设每个 h_{r,k} 的二阶矩为 R，且噪声协方差为 σ²I：

\[
\widehat C_{\rm LMMSE}
=R W^H(W R W^H+\sigma_n^2 I)^{-1}Z.
\]

R∈C^(64×64)描述发射维度相关性。这是空间 LMMSE，当前没有时间/频率插值，没有使用历史地图，也没有完整三维 Kronecker 协方差。矩阵逆通过线性方程求解实现。

本轮 R 只用8个嵌套训练 family、每个4个训练标签估计，共32个训练标签；各 family 等权。每个 H 的 Rx/频率列参与二阶矩统计，但不声称这些列独立。采用固定5%的各向同性收缩保证数值稳定，没有用验证/测试真值调整功率或超参数。

若 R 为真实二阶矩且假设成立，该公式在线性估计器类中最小化均方误差；仅在适当联合高斯条件下等于完整 MMSE 条件均值。本轮训练估计的 R 可能失配，所以真实控制数据中 LMMSE 不保证一定胜过 LS。

### 4.3 发射角域 MMV-OMP

根据已知64阵元的局部几何建立固定平面波字典 A_t∈C^(64×G)。G=195，对应预声明的16×16方向余弦网格中落在单位圆内的点；每列单位范数。令

\[
C\approx A_t S,\qquad Z\approx(WA_t)S+N.
\]

S 在所有 Rx/频率列之间共享非零行支撑，各列系数可不同。它是角域共同稀疏模型，当前没有利用时延稀疏性、Rx角域或 Doppler 稀疏性。每轮按归一化感知原子与残差的 l2 聚合相关性选一列，联合重解当前支撑的复 LS。固定最多8个原子，噪声能量用于停止；没有读取真实路径数。

实现通过 Z Z^H 计算同一 l2 选择分数，避免反复形成大型原子×Rx×频率相关矩阵。它属于传统共同支撑贪婪估计的变体，不是新增理论贡献；也不宣称逐项复现原论文所有规则或定理。[Tropp、Gilbert、Strauss 原始论文](https://tropp.caltech.edu/papers/TGS05-Algorithms-Simultaneous-I-preprint.pdf)。

注意两种限制：一是连续角度不一定落在网格上，存在离网误差；二是欠定测量中的字典原子可能不可区分。固定波束的归一化感知相干性为1，共同支撑不能仅凭更多 Rx/频率列自动变得唯一。当前轮换字典的最大相干性也约0.923，不能套用低相干条件下的通用恢复保证。

## 5. 为什么本轮结果使用理想频域对照

第一次执行保留在 run_01/FAILED.txt（本地运行记录，未随仓库发布）。程序先通过数学控制，随后在真实信道的 CP 条件断言处停止：原CP=64/Fs≈2.083 μs，有的路径时延超过它。该停止没有修改任何数据。

因此将两种观测明确分开：

1. **M0 理想频域观测**：用直接截止时刻的信道，依照 Y=X·(WH) 构造匹配模型的测量，再加入独立复高斯噪声。三种基线的初始比较在这里进行。
2. **原有限 CP 波形诊断**：保持原符号、时刻、CP与分数时延，分别计算冻结信道、动态路径且CFO=0、动态路径且原CFO。这些检查说明 M0 简化在哪里失效。

原始数据的 y 仍然保留；没有为了让公式通过而删长路径、修改CP、改相位或替换未来标签。冻结对照是另外合成的诊断观测，并不能作为原始任务的训练/测试分数。

本轮对8个验证 family 的 pass1 选择最接近真实路线中点、且 cutoff 与整个任务均准入的窗口；选择不依赖算法误差。一个代表窗口含最大约3.645 μs路径，冻结波形相对理想模型的差异约−62.21 dB，说明这次超CP路径的影响较弱，不能只凭最长路径就断言接收机严重失效。另有独立的短CP反例产生明显干扰。实际建模要检查能量及作用，而不只检查几何最大值。

对齐接收FFT窗口后，CP通常需要覆盖残余时延扩展；本接口以已声明的发射时钟及绝对时延生成波形，尚未实施这种独立同步校正。以后增加同步模块时，要同时跟踪时刻、相位与输出CSI的参考定义。

## 8. 下一步怎样走到最终动态任务

建议按以下顺序推进，每次只引入一个可解释的困难。

1. **先读懂并复现M0。** 确认 Y/X 的含义、W 的秩、三个估计器的假设及噪声单位。基线目前都不使用地图，适合作为之后引入地图的公共起点。
2. **建立动态可控模型M1。** 先采用明确的时变基函数或角–时延–Doppler参数模型；用合成单/双径验证从历史到未来的相位与频率映射，再连接真实档案。公共CFO可以先设置为已知的诊断控制，但正式算法不能读取真值。
3. **在相同模型下扩展传统基线。** 预测LMMSE需要未来信道与历史观测的互协方差，而不只是静态R：

   \[
   \widehat h_* = \mu_* + R_{*y}(R_{yy}+R_n)^{-1}(y-\mu_y).
   \]

   这里 R_yy 是无噪声观测协方差，R_*y 包含时间、空间与频率的传播关系。定义清楚以后，再做低秩/参数化实现，避免直接建立巨大的全维协方差。
4. **加入未知CFO、ICI及有限CP。** 用匹配时域波形的前向算子构造似然，检查模型误差；公共CFO与逐径Doppler可能相互混淆，需要空间、运动状态或先验提供约束。
5. **最后加入地图可靠性。** 先比较无地图、固定地图、有限样本可靠性地图，再考虑生成先验或主动补充观测。地图方差不能直接充当未来CSI后验方差。

若采用BEM，h(t)=Σ_q b_q(t)c_q，则简单的静态W变成含时间基的观测矩阵，其列数还会增加；不应误认为增加基函数自动解决欠定性。若采用角–时延–Doppler字典，则可以写 y≈Φ_P(ε)g+n、h*=B_*g；给定字典和CFO时对g线性，但字典失配、稀疏支撑及未知CFO仍需估计。跨时间 path_index 是局部编号，不可直接用作在线已知径关联。

**当前尚未实现的是正式动态预测估计器及它的公平全量评测。** 已完成的部分是能够说明变量、维度、假设、可辨识边界和数值行为的第一层模型，以及可直接继续开发的三种基线。这个边界应在后续每一版结果中继续保留。

基础参考：当前 OFDM LS/LMMSE 的实现方式可对照 [Sionna 官方 channel_estimation 源码](https://nvlabs.github.io/sionna/_modules/sionna/phy/ofdm/channel_estimation.html)；本项目的波束投影与动态任务需要按本文单独建模，不能直接把通用类名等同于匹配当前任务的估计器。
